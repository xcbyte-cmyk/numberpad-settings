# Microsoft Number Pad — 다른 PC로 옮기기

이 PC의 실제 저장된 키 매핑 16개와 관련 매크로 2개를 담았습니다. 개인 계정, 인증 정보, 블루투스 페어링 정보와 전체 Codex 설정은 포함하지 않습니다.

## 다른 PC에서 적용

1. ZIP 압축을 풀고 Microsoft Number Pad를 새 PC에 블루투스로 연결합니다.
2. [Microsoft 공식 안내](https://support.microsoft.com/en-us/surface/accessories/use-microsoft-number-pad)의 다운로드 링크에서 **Microsoft 마우스·키보드 센터**를 설치합니다. 센터를 한 번 열어 Number Pad가 인식되는지 확인합니다.
3. 앱샷도 사용하려면 새 PC에서 Codex를 한 번 실행하고 로그인합니다. 진행 중인 작업을 마친 다음 **파일 → ChatGPT 종료**로 완전히 종료합니다. Microsoft 마우스·키보드 센터 창도 닫습니다.
4. **1-Apply.cmd**를 일반 더블클릭으로 실행합니다. 관리자 계정으로 대신 실행하지 마세요. 현재 로그인한 사용자의 키 설정과 매크로를 복사하고, Codex 설정이 있으면 앱샷 단축키도 지정합니다.
5. `/`와 `*`까지 이 PC처럼 사용하려면 **2-Windows-Shift.cmd**를 실행하고 Windows 관리자 권한 요청을 승인합니다. 이 단계는 F22 → 왼쪽 Shift, F23 → 오른쪽 Shift 두 변환만 추가·교체하며 기존의 다른 Windows 키 변환은 유지합니다.
6. **PC를 한 번 재부팅**하고 Codex와 Microsoft 마우스·키보드 센터를 실행합니다. **Check.cmd**로 저장값을 조회한 뒤 아래 주요 키를 실제로 눌러 확인합니다.

설치·로그인·블루투스 연결은 각 PC에서 한 번 필요합니다. Node.js, Python, 추가 상주 키 변환 프로그램은 필요하지 않습니다. Windows 10/11용이며 Mac에는 적용하지 않습니다.

## 저장한 키 배치

| Number Pad 키 | 저장한 기능 |
| --- | --- |
| 0 | Ctrl + Alt + F24 → Codex 앱샷 |
| / | F22 → Windows 변환 적용 후 왼쪽 Shift |
| * | F23 → Windows 변환 적용 후 오른쪽 Shift |
| - | Tab 한 번 입력 매크로 |
| Backspace | Esc |
| 1 ~ 9 | 차례대로 F13 ~ F21 |
| . | 기본 소수점 입력 |
| 계산기 | 계산기 실행 |
| +, Enter | 별도 매핑 없이 기본 기능 |

1~9가 실행할 프로그램별 동작은 대상 프로그램의 F13~F21 단축키 설정에 달려 있습니다. 이번 묶음은 Number Pad 키 매핑을 옮기며, 다른 프로그램의 개별 단축키 설정은 포함하지 않습니다.

`.`은 기본 소수점 입력으로 복구했습니다. `0`의 활성 기능은 키 조합이며, 남아 있는 이전 매크로 이름은 활성 기능이 아닙니다.

## 범위와 복구

- 1-Apply는 이 PC의 Number Pad 모델 7026 키 설정을 패키지 스냅샷으로 교체합니다. 기존 사용자 정의 Number Pad 매핑은 먼저 백업합니다. 다른 모델의 키보드·마우스, 기기 페어링 및 연결 채널은 옮기거나 바꾸지 않습니다.
- Windows의 F22/F23 변환은 시스템 전체에 적용됩니다. 다른 키보드나 프로그램이 F22/F23을 보내면 그 입력도 Shift가 됩니다. AULA의 일반 숫자·문자 키를 따로 바꾸지는 않습니다.
- 대상 PC의 사용자 설정 백업은 `%LOCALAPPDATA%\NumberPad-Portable\Backups`에 저장됩니다. **Restore.cmd**는 가장 최근 적용 직전으로 복구합니다. 반복 적용하면 복구 기준도 가장 최근 적용 전이 됩니다.
- Windows 변환 백업은 `%PROGRAMDATA%\NumberPad-Portable\shift-before.json`에 저장됩니다. **Restore-Windows-Shift.cmd**로 두 변환을 복구하고 재부팅합니다.
- 실패 메시지가 나오면 성공으로 간주하지 마세요. 사용자 설정 적용 실패 시 Restore.cmd로 복구할 수 있습니다. 복구 전에도 Codex와 Microsoft 센터 창을 종료합니다.
- Codex 앱샷 사용자 지정 단축키는 현재 버전에서 작동 확인된 설정입니다. 다른 버전에서는 별도 확인이 필요하며 설정 화면에서 양쪽 Alt/Shift를 다시 선택하면 덮어써질 수 있습니다.
- 현재 PC에서는 0번 앱샷 실행을 사용자가 확인했습니다. 다른 PC의 실제 입력, 앱샷 첨부와 기기 저장 반영은 대상 PC에서 확인해야 합니다. 이 패키지를 만들면서 현재 PC 설정을 다시 적용하지 않았습니다.

## 문제 발생 시 다른 PC의 Codex에 붙여넣기

> 이 폴더의 사용안내.md와 profile.json을 읽고 Microsoft Number Pad 설정 이전을 도와줘. 먼저 Check.cmd에 해당하는 읽기 전용 확인을 하고, 0의 Ctrl+Alt+F24와 Codex 앱샷 단축키, -의 Tab 매크로, /와 *의 F22/F23 Windows 변환을 각각 확인해줘. 현재 대상 PC 설정을 백업하고 다른 기기·키 매핑과 로그인 정보를 보존해줘. 실행 중인 작업을 중단하거나 강제로 앱을 종료하지 말고, 저장 확인과 실제 물리 키 동작 확인을 구분해줘. 이 패키지에 포함되지 않은 F13~F21의 앱별 기능은 임의로 추측하지 마.
