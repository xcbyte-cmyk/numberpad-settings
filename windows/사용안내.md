# Microsoft Number Pad — 다른 PC로 옮기기

실제로 저장된 키 매핑 16개와 관련 매크로 2개를 담았습니다. 개인 계정, 인증 정보, 블루투스 페어링 정보와 전체 Codex 설정은 포함하지 않습니다.

## 다른 PC에서 적용

1. 저장소 전체 ZIP을 풀고 `windows/`, `codex/`, `shared/` 폴더의 상대 위치를 유지합니다. 이 `windows/` 폴더만 따로 복사하지 마세요. Number Pad를 새 PC에 블루투스로 연결합니다.
2. [Microsoft 공식 안내](https://support.microsoft.com/en-us/surface/accessories/use-microsoft-number-pad)의 다운로드 링크에서 **Microsoft 마우스·키보드 센터**를 설치합니다. 센터를 한 번 열어 Number Pad가 인식되는지 확인합니다.
3. 앱샷도 사용하려면 Codex를 한 번 실행하고 로그인합니다. 진행 중인 작업을 마친 다음 Codex를 완전히 종료합니다. Microsoft 마우스·키보드 센터 창도 닫습니다. 스크립트는 앱을 강제로 종료하지 않습니다.
4. **1-Apply.cmd**를 일반 더블클릭으로 실행합니다. 관리자 계정으로 대신 실행하지 마세요. 현재 로그인한 사용자의 키 설정과 매크로를 복사하고, Codex 설정이 있으면 앱샷 단축키도 지정합니다.
5. Codex 명령별 사용자 지정 단축키도 옮기려면 저장소의 **codex/Apply.cmd**를 실행합니다. 기존의 다른 명령은 유지합니다.
6. `/`와 `*`를 좌우 Shift로 사용하려면 **2-Windows-Shift.cmd**를 실행하고 관리자 권한 요청을 승인합니다. F22/F23만 추가·교체하고 기존의 다른 Windows 키 변환은 유지합니다.
7. **PC를 한 번 재부팅**한 뒤 **Check.cmd**, **codex/Check.cmd**와 실제 입력으로 확인합니다.

일반 사용에는 Windows 기본 PowerShell 5.1이 필요합니다. Node.js, Python, 추가 상주 키 변환 프로그램은 필요하지 않습니다. Windows용이며 Mac에는 적용하지 않습니다.

## 저장한 키 배치

| Number Pad 키 | 저장한 기능 |
| --- | --- |
| 0 | Ctrl + Alt + F24 → Codex 앱샷 |
| / | F22 → Windows 변환 적용 후 왼쪽 Shift |
| * | F23 → Windows 변환 적용 후 오른쪽 Shift |
| - | Tab 한 번 입력 매크로 |
| Backspace | Esc |
| 1 ~ 9 | 차례대로 F13 ~ F21 |
| . | 기본 소수점 입력 |
| 계산기 | 계산기 실행 |
| +, Enter | 별도 매핑 없이 기본 기능 |

1~9의 앱별 기능은 `codex/` 사용자 지정 단축키 또는 대상 프로그램의 설정에 달려 있습니다. `0`의 활성 기능은 키 조합이며, 남아 있는 이전 매크로 이름은 활성 기능이 아닙니다.

## 적용 기준과 복구

적용 기준은 `profile.json`입니다. `numberpad.reg`는 기존 내보내기 참고본이며 자동 적용에는 사용하지 않습니다. 직접 레지스트리 파일을 가져오면 스크립트의 백업·검증 단계를 거치지 않습니다.

1-Apply는 Number Pad 모델 7026의 키 설정을 프로필로 교체합니다. 다른 모델의 기기 설정·페어링·연결 채널은 변경하지 않습니다. Windows의 F22/F23 변환은 시스템 전체에 적용되므로 다른 키보드나 프로그램이 해당 키를 보내도 Shift가 됩니다.

사용자 설정 백업은 `%LOCALAPPDATA%\NumberPad-Portable\Backups`에 저장됩니다. **Restore.cmd**는 가장 최근에 실제로 변경한 적용 직전으로 복구합니다. 설정이 이미 같아 아무것도 변경하지 않은 재실행은 백업과 복구 기준을 갱신하지 않습니다.

Windows 변환 백업은 `%PROGRAMDATA%\NumberPad-Portable\shift-before.json`에 저장됩니다. **Restore-Windows-Shift.cmd**로 복구한 뒤 재부팅합니다. Codex 추가 단축키 백업은 `%LOCALAPPDATA%\NumberPad-Codex-Shortcuts`이며 **codex/Restore.cmd**로 복구합니다.

전체 적용을 되돌릴 때는 **codex/Restore.cmd → windows/Restore.cmd → windows/Restore-Windows-Shift.cmd** 순서입니다. 복구 전에도 앱을 종료하세요. 새 형식의 백업은 이후 변경된 키 설정·매크로·단축키를 감지하면 자동으로 덮어쓰지 않습니다. 이전 백업에는 이 판단에 필요한 정보가 일부 없을 수 있습니다.

실패 메시지는 성공을 뜻하지 않습니다. 레지스트리·매크로 적용 중 실패하면 일부만 적용됐을 수 있으므로 Restore.cmd로 복구합니다. 복구 파일이 없거나 해시가 달라지면 현재 레지스트리를 삭제하기 전에 중단합니다. 복구 도중 오류가 발생하면 백업을 지우지 말고 오류 원인을 해결한 뒤 재시도하세요.

## 확인 범위

기존 내보내기 당시 원래 PC에서는 0번 앱샷 실행과 저장값 일치를 확인했습니다. 이번 코드 변경은 키 배치를 바꾸지 않습니다. 자동 테스트는 실제 드라이버·UAC·재부팅 후 물리 입력을 대신 검증하지 않으므로 새 PC에서 앱샷 첨부와 주요 키를 직접 확인해야 합니다.

문제 해결을 요청할 때는 저장소 루트의 README.md, 이 파일과 profile.json을 함께 제공하세요. 먼저 읽기 전용 Check를 실행하고, 다른 기기·키 매핑·로그인 정보를 보존하며 저장값과 실제 키 동작을 구분해 확인하세요.
